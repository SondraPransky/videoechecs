Favicon de l’Académie

Trois propositions pour l’icône d’onglet des pages de l’Académie, toutes faites avec le pictogramme officiel du logo echecs.com (le Roi et le Cavalier), dans les couleurs de la marque. Chacune est montrée en grand, dans un onglet de navigateur clair et sombre, puis aux tailles réelles. Pour les toutes petites tailles (16 à 48 px), le pictogramme est agrandi pour rester lisible.

À mettre dans le <head> des pages

Les fichiers vont à la racine du site. Le code est le même pour les trois propositions : seuls les fichiers changent.
